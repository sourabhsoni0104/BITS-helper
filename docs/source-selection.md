# Choosing sources for chat

Chat chooses evidence for the requested fact and depth of explanation. There is
no universal rule that handouts or the bulletin always win.

| Question | Preferred evidence |
| --- | --- |
| Course code, title, units, or a catalogue overview | Bulletin entry for the course |
| Topics taught, lecture plan, instructor, textbooks, or assessment details | The matching course handout |
| Degree requirements, CGPA, graduation, and university-wide academic rules | Academic regulations, then applicable official references |
| Lecture/exam times and venues | The timetable for the identified course |
| Semester dates and deadlines | Academic calendar and relevant official documents |
| How to submit a form or complete an academic procedure | The relevant forms, notices, FAQs, and instructions |
| Several kinds of facts in one question | The appropriate sources for each fact |
| An explicit request for a source | The requested source |

Course-specific sources must match the course; another course's matching
keywords do not count. Abbreviated titles and follow-ups use the same course
resolution as handout questions. Multiple plausible offerings require
clarification.

If the preferred evidence does not answer a question, retrieval can use a relevant
fallback. It labels that fallback and instructs the answer to explain its limits.
For example, a missing handout may leave only a catalogue overview, which cannot
establish the current detailed teaching plan. Mixed questions mark missing source
types rather than pretending that all requested details were verified.

A code lookup receives a short answer and citation. An overview remains brief;
a question asking for teaching details receives the relevant detailed material.
Every institution-specific factual claim still requires supporting citations.
